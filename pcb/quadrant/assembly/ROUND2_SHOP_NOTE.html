Chess board PCB — round 2

New board to solder fully (same parts as last time) — but the sensor direction on the last board came out backwards, so this sheet adds one strict rule and one test. Everything else follows the original job sheet.

⚠ Sensor direction — the last board was wrong

These sensors are a mirror-pinout batch. The printed "3144" face must look at the STRAIGHT edge of the white outline — NOT the curved side.

The sensor must look WRONG inside its outline. If it looks like it matches the outline nicely, it is backwards.

A sample board with ONE sensor placed the correct way comes with this sheet — copy that sensor exactly, all 16 positions.

After soldering, bend each sensor 90° so the body lies flat on the board, printed face touching the PCB. Bend once, gently — the legs snap if re-bent.

Order of work — S0 first customer stays for step 2

  1. Solder only these three parts first: connector J1 (6-pin header, left edge), sensor S0 (corner square, the correct way, bent flat), resistor R0.
  2. Customer runs a 2-minute test with his controller board and a magnet. A blue light confirms the sensor direction is right.
  3. Light works → solder everything else exactly like the original job sheet (all 16 sensors same direction as S0, bent flat).
  4. Light does not work → STOP. Nothing else gets soldered that day.
